# Bitten von U2 (Klang)

Die Klangwelt liegt in `src/audio.js` (Schnittstelle unverändert: `new Audio(settings)`, `start()`,
`applyVolumes()`, `update(game, engine, dt)`, `play(name, opts)`) und `src/audio/*.js`.
Alle Bitten sind optional – ohne sie funktioniert alles, es fehlen nur die jeweiligen Klänge.

## Für alle: Klänge auslösen ohne Zugriff auf die Audio-Instanz

Systeme (sim/) und Ansichten (render/) kennen `app.audio` nicht. Deshalb hört die Klangwelt auf den
Ereignisbus aus `registry.js`:

```js
import { emit } from '../registry.js';
emit('sound', 'siren', { x: b.x, y: b.y });   // beliebiger Klangname, optional mit Feldposition
```

Mit `{ x, y }` (Feldkoordinaten) oder `{ wx, wz }` (Welt) wird der Klang räumlich (Panorama, Entfernung
zur Kamera; zu weit weg = stumm), mit `far: true` bleibt er auch aus der Ferne hörbar.
Klangnamen: `click hover tab toggle open close pop whoosh speed pause resume photo place road zone demolish
complete levelup line error milestone achievement unlock card money loan bad good notify warn bankrupt
season busStop plane helicopter train ship horn bell churchbell fire extinguish thunder storm siren
disaster quake explosion meteor tornado flood` (Aliasse: `fanfare`, `cash`, `ui`). Jeder Name hat eine
Mindestpause, Dauerfeuer ist also unschädlich.

## U1 – Oberfläche (`ui/ui.js`, `ui/menu.js`)

1. **Regler „Umgebung"** im Abschnitt Klang (neben Gesamt/Musik/Effekte). `audio.js` liest bereits
   `settings.ambience` (0..1, Standard 1, wirkt relativ zu „Effekte"):
   ```js
   <div class="slider"><label>Umgebung</label><input type="range" min="0" max="1" step="0.05" value="${s.ambience ?? 1}" data-set="ambience" id="set-ambience"><span class="val num">${Math.round((s.ambience ?? 1) * 100)}</span></div>
   ```
   `panelInput` behandelt `data-set` schon generisch und ruft `applyVolumes()` – nichts weiter nötig.
   Bitte `ambience: 1` in die Standardwerte von `loadSettings()` (main.js) aufnehmen, falls ihr dort ändert.
2. **Neue Oberflächenklänge** (alle leise und im Akkord der Musik):
   - Panel öffnen/schließen: `play('open')` / `play('close')` statt `play('click')`
   - Schalter (Toggle) umlegen: `play('toggle')`; Reiter wechseln: `play('tab')`
   - Fotomodus auslösen: `play('photo')`
   - Benachrichtigungszentrale: neue Meldung `play('notify')`, gute Nachricht `play('good')`, Warnung `play('warn')`
   - Meilenstein-Fenster mit Freischaltungen: zusätzlich `play('unlock')` (etwa 0,8 s nach `milestone`)
   - Kredit aufnehmen: `play('loan')` statt `money`
3. Geschwindigkeitswechsel und Pause bekommen ihren Klang automatisch (`audio.update` erkennt `g.speed`).

## S3 – Verkehr & ÖPNV (`sim/systems/transport.js`)

1. Wenn ein Bus an einer Haltestelle hält: `emit('busStop', { x, y, line })` (Feldkoordinaten der Haltestelle).
   Bremsenzischen, Diesel und Türgong; nur in Kameranähe hörbar.
2. Start/Landung am Flughafen: `emit('plane', { x, y, phase: 'takeoff' | 'landing' })` → Düsenüberflug.
3. Fernzug fährt ein: `emit('sound', 'train', { x, y })` → Bahnhofsgong.
4. Fähre legt ab: `emit('sound', 'ship', { x, y })` → Schiffshorn.
5. Die `renderables`-Arten aus SWARM 6.3 werden schon für Nahgeräusche genutzt (`police/fire/ambulance` →
   Martinshorn mit Doppler, `plane`, `helicopter`, `ship_*`/`ferry`/`boat`, `bus`/`tram`, `train_loco`,
   `snowplow`). Bitte `x`/`z` in Weltkoordinaten liefern (wie im Vertrag).

## S4 – Wetter & Katastrophen (`sim/systems/weather.js`, `sim/systems/disasters.js`)

1. `g.ext.weather.lightning`: bitte als kurzen Puls (≥ 0,4 für einen Augenblick, sonst 0) setzen – die
   steigende Flanke löst Donner aus (nah: Wert > 0,8, kurzer Abstand; fern: längere Laufzeit).
2. `emit('disaster', { type, phase, x, y, intensity })` wie in 6.5. Erkannte Typen (Teilwort, Groß/Klein egal):
   `quake|beben`, `torn|wirbel`, `flood|flut|hochwasser`, `meteor`, `storm|sturm|orkan`, `light|blitz`,
   `fire|brand|feuer`. `phase: 'warn'` spielt die Zivilschutz-Sirene, `start` den Einschlag/das Ereignis,
   aktive Katastrophen halten die Musik im Spannungsabschnitt, `end` löst sie wieder.
3. Jahreszeitenwechsel: `emit('season', 'winter')` (oder `{ season }`) → kurzes Jahreszeiten-Motiv.
4. Warnsirenen-Gebäude (`warning_siren`) bei Vorwarnung: `emit('sound', 'siren', { x, y, far: true })`.

## S5 – Fortschritt (`sim/systems/progression.js`, `ui/panels/progression.js`)

1. Erfolg freigeschaltet: `emit('achievement', { id })` → Erfolgs-Fanfare (kleiner als der Meilenstein).
2. Szenario gewonnen: `emit('sound', 'milestone')`, verloren: `emit('sound', 'bankrupt')`.

## Hinweis für alle Prüfungen

`window.__stadtpuls.audio.stats()` zeigt Stimmung, Abschnitt, wache Klangbetten, Ereignisse und die
Hörort-Analyse; `await window.__stadtpuls.audio.selfTest({ parts: ['sfx'] })` rendert offline und meldet Pegel.
