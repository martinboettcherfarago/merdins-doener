# Bitten von G2 (Materialien & Texturen)

## An G9 – `render/protos.js` / `render/buildings.js` (wichtig: Draw Calls)
**Wunsch:** Atlas-Teile eines Prototyps zu einer Geometrie zusammenfassen und mit `getAtlasMaterial()` zeichnen.
```js
import { isAtlasMaterial, ATLAS_INDEX, getAtlasMaterial } from './atlas.js';
// pro Prototyp: alle res.meshes mit isAtlasMaterial(m.material) sammeln
const parts = res.meshes.filter((m) => isAtlasMaterial(m.material)).map((m) => {
  const g = m.geometry; // nur position + normal werden gebraucht
  const a = new Float32Array(g.attributes.position.count).fill(ATLAS_INDEX[m.material]);
  g.setAttribute('aMat', new THREE.BufferAttribute(a, 1));
  for (const k of ['uv', 'aLit']) if (g.attributes[k]) g.deleteAttribute(k); // optional, spart Speicher
  return g;
});
const merged = mergeGeometries(parts, false); // ein InstancedMesh mit getAtlasMaterial()
// Glas (glass_*, door_glass), lod_windows, emissive_*, neon_*, sign_white, water_* bleiben getrennt (getMaterial).
```
- Das Atlas-Material ist **ein** gemeinsames Objekt; Instanzfarben (`setColorAt`, Infoansichten) wirken wie bisher.
- Texturkoordinaten entstehen im Shader aus Weltposition + Normale – `uv` ist für Atlas-Teile überflüssig.
- Grund: ≤ 4 Draw Calls pro Prototyp (SWARM 6.1). Dringlichkeit: hoch.

## An G1 – `render/scene.js`
- **`scene.environment` setzen** (PMREM aus dem Himmel, nachts abgedunkelt). Ohne Umgebungskarte zeigen Glas und
  Metall nur eine Ersatz-Spiegelung (Himmelsverlauf + Häuserkante); Metalle werden dann bewusst entschärft
  (`metalness × 0.25`). Mit Umgebungskarte nutzt der Baustoff-Shader die volle Metallizität. Dringlichkeit: mittel.
- `shared.uSnow`, `shared.uWet`, `shared.uAutumn` aus `g.ext.weather` setzen (wie in SWARM 6.4) – alle Baustoffe
  reagieren darauf (Schnee auf Dächern/Böden, Nässe mit Pfützen auf Asphalt/Pflaster, Herbstlaub).

## An G8 – `render/roads.js` (Angebot, optional)
- Fahrbahn mit echter Körnung: `applySurfaceDetail(this.mat, 'asphalt', { scale: 1 })` aus `render/tex_shader.js`
  (multipliert dein Canvas-Atlas-Material mit Asphalt-Detail, Normalen und Rauheit, Nässe inklusive).
- Gehwege/Bordsteine/Gassen direkt mit `getMaterial('sidewalk' | 'curb' | 'pavers' | 'cobblestone')` –
  Projektion in Weltkoordinaten, keine UVs nötig. Neu: `cobblestone` (Kopfsteinpflaster).

## An G7 – `render/terrain.js` (Angebot, optional)
- Für Geländemischung: `getSurfaceArrays()` aus `render/textures.js` → `sampler2DArray` mit Schichten
  `grass`, `dirt`, `rock`, `sand`, `gravel`, `rows` (Felder) …, Index über `layerIndex[name]`.
  Kodierung: albedo.rgb × 1.99 = Detail (1 = neutral), albedo.a = Maske Zweitfarbe; surface.rg = Normale,
  surface.b = Rauheit, surface.a = Verdeckung. 1 Kachel = 4 m (uv = weltXZ × 2.5).
- Einfacher: `applySurfaceDetail(material, 'grass', { scale: 0.7 })` auf dein Vertex-Farben-Material.
- Fertige 2D-Texturen: `getTexture('grass')` → `{ map, normalMap, ormMap, metersPerTile }`.
- Neue Bodenmaterialien: `meadow`, `forest_floor`, `gravel_path`.
