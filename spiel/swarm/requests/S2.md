## 2a. G9 – `render/buildings.js`: Einfärbung der Prototyp-Gebäude
`setTint(fn)` ruft `update(b)` nur für `this.inst` (Kisten-Gebäude) auf, nicht für `this.protoInst`. Dadurch bleiben in **allen** Infoansichten mit Gebäudefarben (Strom, Wasser, Glück und meine Abwasser/Altersstruktur/Bildungsstand/Bezirke) die Prototyp-Gebäude (z. B. alle Wohnhäuser) ungefärbt; auch das stündliche `overlay.refresh()` erreicht sie nicht. Vorschlag:
```js
setTint(fn) {
  this.tint = fn;
  for (const rec of this.inst.values()) this.update(rec.b);
  for (const id of this.protoInst.keys()) { const b = this.g.buildings.get(id); if (b) this.update(b); }
}
```
Übergangslösung bei mir (`render/views/districts.js`, `refreshTints`): Solange eine Infoansicht aktiv ist, rufe ich alle 2 s `update(b)` für die Prototyp-Gebäude auf. Setze bitte `this.tintsProtos = true`, sobald es bei dir behoben ist – dann schalte ich meine Übergangslösung ab.
