# Bitten von G3 (Architektur Wohnen & Gewerbe)

## An G9 (Gebäude-Renderer) – `render/buildings.js`, `render/protos.js`

1. **Nachtlichter der Prototypen zeichnen** (Dringlichkeit: mittel)
   Die Modelle für `res`/`com` liefern über `kit.light(x, y, z, farbe, größe)` Lichtpunkte für Hauslampen,
   Schaufenster, Leuchtschriften, Laternen, Tankstellendächer und Flugwarnlichter (`res.lights`, lokal zum
   Grundstück, Front = +z). `ProtoManager.get` speichert sie bereits in `proto.lights`, gezeichnet werden sie
   noch nicht. Vorschlag (analog zu den Emittern in `addProto`):
   ```js
   const ls = proto.lights.map((l) => ({ x: ox + l.x * cs + l.z * sn, y: l.y, z: oz - l.x * sn + l.z * cs, color: l.color, size: l.size }));
   if (ls.length) this.nightLights.set(b.id, ls);
   // jedes Bild bei night > 0.25: engine.effects.lights.add(x, y, z, size, r, g, b, 0.55 * night)
   ```
2. **Detailstufen** (Dringlichkeit: mittel)
   Alle Wohn-/Gewerbemodelle unterstützen `detail` 0/1/2 sauber (Detail 0 ≤ 8 % des Budgets, Fenster als
   `lod_windows`-Raster mit einer UV-Zelle je Fenster). `ProtoManager.get` baut im Moment immer Detail 2.
   Bitte `buildArch(key, level, variant, fw, fd, extra, detail)` je Entfernungsstufe aufrufen.
3. **Hinweis zur Geometrie**: Alle Teile kommen mit eigenen, flächenbezogenen UVs (`uv: 'keep'`, 1 UV = 4 m,
   auf Dachflächen u entlang der Traufe, v hangaufwärts) und dem Attribut `aLit` (Glas: Zufallswert je
   Fenster, sonst 0). Beim Zusammenführen der Atlas-Teile bitte `uv` und `aLit` übernehmen.
4. Sondermaterialien je Modell: Wohnen ≤ 3, Gewerbe ≤ 5 (Glas, Schaufensterglas, ggf. Vorhangglas,
   ein Leuchtschrift-Material je Gebäude, `sign_white` für Lampen).

## An G2 (Materialien) – `render/matlib.js` (nur ergänzen)

Wünsche für neue Namen (G3 nutzt bis dahin Ersatz):
- `glass_railing`: mattes, leicht bläuliches Glas für Balkonbrüstungen **ohne** Nachtbeleuchtung
  (`[0xb9cdd6, 0.2, 0.3]`, nicht `glass: true`). Ersatz derzeit: `metal_panel_white`/`metal_light`.
- `ivy`: dichtes Efeublattwerk für Brandwände (`[0x3d6b3a, 0.95, 0]`). Ersatz: `hedge`/`leaves_dark`.

Texturhinweise, die meine Modelle gut aussehen lassen würden:
- `awning_striped`: Streifen entlang **u** (die Markisenfläche hat u entlang der Fassade).
- `roof_tiles_*`, `roof_slate`: Ziegelreihen entlang **u** (= Traufrichtung), v = hangaufwärts.
- `pavers`, `sidewalk`: kleinteilig (Ladenvorplätze, Höfe).
