# G10 – Fahrzeuge & Leben: Hinweise und Bitten

## Für alle Systeme, die `renderables(g)` liefern (S1, S2, S3, S4 …)

G10 zeichnet jede Art aus Vertrag 6.3. Felder:

| Feld | Bedeutung |
|---|---|
| `kind` | `car, van, truck, bus, tram, taxi, police, fire, ambulance, garbage, hearse, snowplow, tanker, train_loco, train_wagon, cargo_wagon, ship_cargo, ferry, boat, sailboat, plane, helicopter, ship_cruise, metro, minibus` |
| `x, y, z, yaw` | Welt-Koordinaten; `yaw = atan2(dx, dz)` der Fahrtrichtung (Modell-Front +z). Fehlt `y`, nimmt G10 die Fahrbahnhöhe. |
| `pitch`, `roll` | optional; `pitch` als Euler-X in Reihenfolge `'YXZ'` (wie S3): **negativ = Nase hoch** |
| `color` | Lackfarbe (Zahl oder `'#rrggbb'`). Bus/Straßenbahn: Linienfarbe. |
| `len` | Länge in Welteinheiten. Skaliert entlang z bei `tram, train_*, cargo_wagon, ship_*, ferry, boat, metro`. Kurze Längen bekommen eigene Modelle: `train_loco` < 1.4 → Rangierlok, `cargo_wagon` < 1.3 → kurze Güterwagen, `ship_cargo` < 3.5 → Binnenschiff. |
| `lights` | `true` = Scheinwerfer an (auch tagsüber); Einsatzfahrzeuge (`police, fire, ambulance`) und `garbage, snowplow` haben Blaulicht/Rundumleuchte, außer `lights: false`. |
| `id` / `variant` | optional, stabiler Zufallswert (Modellvariante, Fensterlicht). Ohne `id` wird der Listenindex genutzt – bitte die Reihenfolge stabil halten. |
| `lead`, `brake`, `pal` | optional: Bahn-Spitzenlicht vorne, Bremslicht, Zweitfarbe 0–7 (Kofferaufbau, Container) |
| `freight` | Lkw der Wirtschaft (S1) → Koffer-Lkw oder Tankwagen |
| `segment` | Straßenbahn-Teile (S3): 0 = Kopf, letztes Teil (höchste `segment` derselben `id >> 2`) = gedrehter Kopf, dazwischen Mittelteile (Modelle für `len` 1.15) |
| `siren`, `wreck` | Blaulicht an/aus (vor `lights`); Unfallwagen dunkler, leicht geneigt, ohne Licht |

Gleichmäßig skaliert (Breite und Höhe mit) werden `plane, ferry, ship_cruise, ship_cargo, boat, sailboat, helicopter`; Busse ab `len` > 1.4 (Gelenkbus) nur in der Länge. Kurze S3-Züge: `train_loco` < 0.85 → kurzer Triebkopf, `train_wagon` < 1.3 → kurzer Reisezugwagen. `VehicleView.drawsRenderables = true` ist gesetzt.

Standardlängen der Modelle (ohne `len`): Pkw ≈ 0.36–0.48, Bus 1.2, Straßenbahn 2.4, Lok 1.9, Reisezugwagen 2.6, Güterwagen 1.8, Fähre 2.0, Containerschiff 5.0, Kreuzfahrtschiff 6.5, Boot 0.55, Flugzeug 3.8, Hubschrauber 1.3.
Schiffe: `y` = Wasserlinie (`engine.terrain.waterLevel`, −0.14), der Rumpf reicht darunter.

## G8 – Straßen & Stadtmobiliar
- **Parkende Autos:** gern die G10-Modelle nutzen: `import { vehicleGeometry, getVehicleMaterial, carPaint, carType } from './vehicles_models.js'` → `new THREE.InstancedMesh(vehicleGeometry(carType(u), 1), getVehicleMaterial(), n)` mit `setColorAt` (Lackfarbe). Detail 2 = nah, 1 = mittel. Bitte die Geometrie klonen, wenn ihr eigene Instanz-Attribute setzt.
- **Bitte (optional):** `RoadView.surfaceY(i)` (Fahrbahnhöhe je Feld) und `RoadView.sidewalkY` (Oberkante Gehweg) anbieten, falls sie von 0.012 bzw. Brücke 0.24 abweichen. G10 benutzt beides automatisch, wenn vorhanden (`agents.js` → `roadY`, `views/life.js` → Fußgängerhöhe).
- Fußgänger laufen auf `ROAD_GEOM[typ].width/2 + sidewalk/2` neben der Straßenmitte, Radfahrer auf `width/2 − 0.045`.

## G6 – Pulsbahn-Station
- `TransitView.placeArchStations` nutzt `registerArch('station')` in den Detailstufen 2/1/0 (nach Kameraabstand, alle 20 Bilder neu verteilt), gedreht in Richtung der ersten Linie (Modell-z = Fahrtrichtung). Die Zonen-Symbole schweben bei `trackHeight + 0.51`, also knapp über eurem Dach (+0.475).

## G1 – Licht
- Scheinwerfer, Rücklichter, Blaulicht, beleuchtete Fenster sind Emission im Fahrzeug-Material (`vehicles_kit.js`) plus eigene additive Leuchtpunkte (je Ansicht ein Draw Call, nur nachts/bei Blaulicht sichtbar). Der `lights`-Parameter von `VehicleView.frame` wird nicht mehr gebraucht, darf aber bleiben.
- Gibt es `scene.environment`, schaltet das Material automatisch auf echte Metall-/Glas-Spiegelung (`VU.uEnv`); ohne Umgebungskarte gibt es eine Ersatz-Himmelsspiegelung auf Glas.
- Wetter: Bei Nebel, Regen, Schnee, Sturm schalten Fahrzeuge das Licht auch tagsüber ein (`g.ext.weather`).
